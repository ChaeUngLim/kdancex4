# kdance Constitution

> **이 파일은 원본이 아니다.** kdance 의 행동 규칙 원본은
> **`.claude/rules/core-rules.md`** 하나뿐이다. spec-kit 스킬이 constitution 을
> 찾을 때 읽을 자리라서 남겨 두지만, 내용은 여기서 정하지 않는다.
>
> **`/speckit-constitution` 을 실행하지 않는다.** 실행하면 이 파일에 원칙을 새로
> 쓰게 되어 규칙 원본이 둘로 갈라진다. 원칙을 고칠 일이 생기면 `core-rules.md` 를
> 고친다.

| 프로젝트 개요 | `CLAUDE.md` |

## 이 프로젝트에서 절대 어기지 않는 것

전문은 `core-rules.md` 에 있다. 여기에는 spec 을 쓸 때 특히 걸리는 것만 옮겨 둔다.

1. **한국어로 쓴다.** 코드 식별자와 라이브러리 표준 용어는 원문 유지.
2. **번호만 쓰지 않는다.** `SCH-04(어댑터 3종)` 처럼 기능명을 붙인다.
3. **버전을 추정하지 않는다.** 실제 파일이나 레지스트리에서 읽는다.
4. **미검증은 미검증이라 적는다.** 확인하지 못한 것을 확인한 것처럼 쓰지 않는다.
5. **수용 기준은 검증 가능한 형태로.** "잘 동작한다" 가 아니라 실행할 명령과 기대 결과로.
