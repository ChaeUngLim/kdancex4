# Sweep A (spec 596~1146행)

점검일 2026-11-09. 읽기 전용. 근거는 `board_texts.md` 글자 grep 으로 확인했고, 「이전 안」·「폐기」 보드는 근거로 쓰지 않았다.

## 관리자 웹(admin-web) 보드 현황

- **있음**: O1(대시보드), O2(포스터로 수업 등록), O3(환불 요청 처리·행사 일괄 취소), O4(정산·원장) — 사이드 메뉴 「K-DanceX4 콘솔」, 대표 콘솔.
- **메뉴만 있고 보드 없음**: 예약·명단, 1+1·순위판(O1 대시보드 카드로만 일부 보임), 입점·설정.
- **운영자(Admin) 콘솔 보드 없음**: 입점 승인, 증빙 확인, 허위 인증 회수, 환불 실패 재시도 등 운영자 화면이 어느 보드에도 없다.
- 대표 앱(OA1~OA4 조회 전용, O5~O8, O21, O22, O5P)은 별도 모바일 보드로 있다.

## 현재 spec 과 어긋난 보드

- **M3(가입 정보)**: 대학생 인증을 「모바일 학생증 또는 학생증 사진」으로 안내. spec FR-006 은 학교 이메일(.ac.kr) 인증이고 M17·M12 는 이메일로 맞게 적혀 있다. M3 문구를 고쳐야 한다.
- **회원 이름 표기(FR-019a 닉네임, 판단 근거 약함)**: OA3(대표 앱 회원)·O3(환불 요청)·O4(원장)·I6(회원 관리)·I10(개인 레슨)이 이름을 그대로 보여 준다. 본명을 닉네임으로 쓸 수 있어서 위반이라고 단정하진 않는다. 닉네임 표기가 확실한 곳은 I21·O21·O22 뿐이다.
- **M1(로그인)**: 14세 미만 보호자 자녀 등록을 문구로만 안내하고 이어지는 화면이 없다(어긋남은 아니고 공백).
- **현재 spec 과 반대인 「이전 안」 보드(근거로 쓰지 않음)**: M1A(세 번 누르기 입구, 앱 분리로 삭제), I9B(강사 활동 장르 바꾸기, 현재는 가입 때만 고르고 바꾸지 않음), I3(명단·출석 체크 화면, I6 으로 이동), I1 이전 안(새 반 열기 추천 카드·5탭), I8 이전 안(안내 카드+잠긴 표), I9D(7색 학원 색), R1·S1~S4(재방문 장르 카드, 2026-10-04 폐기), O5·O6·O7 이전 안(공통 컴포넌트 전), M8C 이전 안(두 달 달력).
- 이전 안 보드가 근거 없는 현재 보드와 같은 자리에 겹쳐 있지 않은지(캔버스 y34054 줄 등) 정리가 필요하다.
