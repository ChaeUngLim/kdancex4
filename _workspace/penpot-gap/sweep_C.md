## 현재 spec 과 어긋난 보드
- M16 · 내 예약 · 결제 내역: 「환불 요청은 문의로 접수돼 담당 강사가 확인하고, 금액은 그 학원 대표가 정해요」 — spec 은 환불 요청을 대표만 받는다(FR-189 삭제 사유, 2026-09-25). 「담당 강사가 확인」 부분이 어긋날 수 있다(판단 근거 약함, 범위 밖 FR 의 문구).
- M26B · 카드 크게 보기: 「프로필과 홈에는 세부 장르별 지금 레벨 카드만 보여요」 — 마이(M12)·홈(M7)에 카드 자리가 없고, M25C 의 「마이 › 레벨 카드」 진입 줄도 M12 에 없다. 보드끼리 어긋남.
- M25B · 카드 받기 선택: spec FR-169d ② 는 회원이 「이 레벨로 승급하기 / 지금 레벨에서 내가 키우기」를 고른다고 적었는데 보드는 「예, 받을게요 / 아니오」(카드 발급 선택)다. FR-169e 의 M25B 설명과는 맞고 FR-169d 문구와는 용어가 다르다.
- I6C · 오늘 결석자 보드 이름에 「FR-169a」가 붙어 있으나 FR-169a 의 「강사 결석 체크」 문단은 옛 규칙으로 남아 있다(spec 에 미정 표시). 보드는 조회 전용으로 현재 결정과 맞다.
- 「이전 안」 보드 중 현재 spec 과 반대되는 내용은 이 범위에서 따로 발견하지 못했다(I3 명단·출석·레벨 이전 안은 근거에서 제외).
