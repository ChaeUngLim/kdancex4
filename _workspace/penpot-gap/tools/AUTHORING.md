# Penpot 보드 스크립트 쓰는 법 (에이전트용)

보드는 **JavaScript 조각 파일**로 쓴다. 오케스트레이터가 `python3 pp.py lib.js boards/member_lib.js boards/<파일>.js` 처럼 앞에 도우미를 붙여 Penpot 플러그인에서 한 파일씩 순서대로 실행한다. 에이전트는 **파일만 쓰고 실행하지 않는다**(플러그인은 한 번에 한 작업만 받아 동시에 부르면 막힌다).

## 반드시 지킬 제약
1. **한 파일에 도형 40개 이하.** `R`·`T`·`BTN`(도형 2개)·`CARD`·`CHIP`(2개)·`TOG`(2개)·`RADIO`·`CHECK`(1~2개)·`INPUT`(2개) 호출 수로 센다. 넘으면 `_1.js`, `_2.js` 로 나눈다. 이 페이지는 도형이 많아 40개만 넘어도 30초 제한에 걸린다.
2. 첫 파일(`_1.js`)만 보드를 만든다: `const B=PAGE_M('<보드 이름>',<slot>,'<화면 제목>');` 둘째 파일부터는 `const B=FIND('<보드 이름 앞부분>');` 로 찾는다. `FIND` 는 이름이 그 글자로 **시작하는** 보드를 찾으니 `'C9A ·'`처럼 가운뎃점까지 넣어 다른 보드와 겹치지 않게 한다.
3. 좌표는 모두 **보드 왼쪽 위 기준**이다. 화면 폭 390, 높이 928. 좌우 여백 20(내용 폭 350). 위쪽 0~70 은 상태바와 「‹ 제목」, 아래쪽 844~928 은 하단 탭이다 — **내용은 y 84~770** 안에 둔다. 맨 아래 주 버튼은 `BTN(B,20,778,'문구','primary',{w:350,h:54,r:18,fs:15})`.
4. 글자는 자동 크기가 안 된다. `T` 가 폭을 추정해 잡는다. **여러 줄이 될 글은 반드시 `{w:폭}` 을 준다**(줄 수를 추정해 높이를 잡는다). 한글 1글자 ≈ 글자크기 × 1.07 px. 11px 글은 350 폭에 약 29자, 12px 는 약 27자, 14px 는 약 23자가 한 줄이다. 줄이 넘칠 것 같으면 문구를 줄이거나 아래 요소의 y 를 넉넉히 띄운다(한 줄 높이 = 글자크기 × 1.5).
5. 이미 있는 글자의 내용을 바꾸는 코드(`characters = ...`)는 화면에 반영되지 않는다. 쓰지 않는다. 새로 그린다.
6. 색은 `C` 상수만 쓴다. 강조는 플럼(`C.plum`), 옅은 플럼 바탕(`C.plumL`), 선택 바탕(`C.sel`+테두리 `C.selLine`), 경고(`C.warn`·`C.warnL`), 카드 흰색, 보조 글 `C.ink3`, 본문 보조 `C.ink2`. **녹색·갈색·주황은 쓰지 않는다.**
7. 마지막 줄은 `return B.id;`. `export`·`setTimeout`·`await` 로 기다리기·삭제(`remove`)는 쓰지 않는다.

## 도우미 (lib.js)
```js
R(B,x,y,w,h,fill,{r,stroke,sw,dash,name})          // 사각형. fill 은 색 문자열 또는 null
T(B,x,y,'글',크기=14,'굵기'='500',색=C.ink,{w,align:'center'|'right',lh})  // 글자. 굵기는 '500'·'600'·'700'·'800'
BTN(B,x,y,'문구','primary'|'ghost'|'danger',{w,h,r,fs})
CARD(B,x,y,w,h,{r,fill,stroke})                     // 흰 카드(테두리 있음). 모서리 기본 18, 앱 화면은 {r:16}
CHIP(B,x,y,'문구',바탕=C.plumL,글자색=C.plum,크기=12) // 높이 24. 폭을 돌려준다
TOG(B,x,y,on)                                       // 토글 36x20
RADIO(B,x,y,on)                                     // 라디오 20x20
INPUT(B,x,y,w,'값',{h,fs,fw,col})                   // 입력칸(높이 기본 36)
tw('글',크기)                                        // 글 폭 추정(px)
```
## 도우미 (boards/member_lib.js — 회원 화면)
```js
PAGE_M('<보드 이름>',slot,'<화면 제목>',H=928)  // 회원 앱 틀: 상태바 + ‹ 제목 + 회원 하단 탭. slot 은 배정받은 칸 번호
CHECK(B,x,y,on,dim)                             // 체크박스 22x22
```
## 도우미 (boards/page_lib.js — 강사 화면)
```js
PAGE('<보드 이름>',minX,'<화면 제목>',H=928)   // 강사 앱 틀(강사 하단 탭). minX 부터 빈 자리를 찾아 놓는다
```

## 본보기 — 실제로 실행해 확인한 파일
- `boards/i14_1.js`·`i14_2.js` (대타 요청: 카드·목록·체크·단계 칩·버튼)
- `boards/i15_1.js`·`i15_2.js` (조건 카드·결과 카드·확인 상자)
- `boards/i15b_1.js` (명단 줄 반복)
줄 반복은 `배열.forEach(([a,b],i)=>{const y=시작+i*간격; ...})` 로 쓴다. 한 줄에 글이 세 줄(이름·설명·보조)이면 간격은 72 이상.

## 보드 이름
`<ID> · <화면 이름> (<핵심 규칙 요약>)` — 예: `C9A · 환불 계좌 입력 (가상계좌·계좌이체 결제분 · 예금주 본인 확인)`. ID 는 배정받은 묶음 번호에 A·B·C 를 붙인다.

## 화면 내용 원칙
- 근거는 `specs/001-ai-dance-class-platform/spec.md` 의 FR 이다. spec 에 없는 규칙을 화면 문구로 지어내지 않는다. 화면을 그리려면 정해야 하는데 spec 에 없는 것은 가장 무난한 안으로 그리고 **노트 파일에 「추천안」으로 적는다.**
- 문구는 회원에게 말하듯 「~해요」체. 번역투·피동 남발을 피한다. 예시 데이터는 기존 보드와 맞춘다: 학원 「라틴하우스 강남」, 수업 「바차타 센슈얼 입문」「살사 온원 입문」「쌈바(입문)」, 강사 「이준호」「김하나」, 회원 「김서연」. 날짜 요일은 실제 달력과 맞춘다(2026년 11월 1일은 일요일).
- 하단 탭은 틀이 넣어 준다. 지우지 않는다.
- 2026-11-10 결정: 이벤트·원데이·파티·공연·대회는 간편 계좌이체(기본)·가상계좌만(카드·간편결제 없음). 정규·단기·개인 레슨은 신용·체크카드 기본. 결석은 회원이 `참석 | 결석` 토글로 알린다. 「구독」은 학원 소식 받기에만 쓰고 유료는 「멤버십」. 「쌈바」 표기. Owner 는 「대표」.

## 추가 도우미 (2026-11-10 밤)
```js
// boards/owner_lib.js — 대표 앱(휴대폰) 화면. 실행: lib.js boards/owner_lib.js <파일>
PAGE_O('<보드 이름>',3080,'<화면 제목>',H=928)   // 대표 하단 탭. 제목은 (46,49) 20px. 내용은 y 94~(H-100)
// boards/web_lib.js — 대표 관리자 웹(1280폭). 실행: lib.js boards/web_lib.js <파일>
WEB('<보드 이름>',slot,'<켜질 사이드 메뉴>',H=832)  // 사이드 메뉴 포함. 내용은 x 268~1248
// 사이드 메뉴 이름(MENU): '대시보드','수업 · 포스터 등록','예약 · 명단','강사 관리','학원 공지','환불 처리','정산 · 원장','1+1 · 순위판','입점 · 설정'
```
- 관리자 웹 보드의 관례: 제목 `T(B,268,30,'제목',28,'800')`, 설명 `T(B,268,72,'…',14,'500',C.ink3)`, 오른쪽 위 주 버튼 `BTN(B,1104,36,'…','primary',{w:144,h:40})`, 카드는 y 112 부터 `CARD(B,268,112,980,높이)`. 표는 열 제목(12px, C.ink3) + 구분선 `R(B,x,y,w,1,C.line)` + 줄 간격 46~58. 본보기는 `boards/` 에 없으니 이 관례대로 쓴다(웹 보드는 도형이 많아지기 쉬우니 파일을 더 잘게 나눈다 — 사이드 메뉴가 이미 30개쯤 쓴다. **`WEB(...)` 를 부르는 첫 파일에는 제목·설명·버튼까지만 넣고 나머지는 둘째 파일부터**).
- 강사 화면은 `PAGE('<이름>',1760,'<제목>')` — 실행: `lib.js boards/page_lib.js <파일>`.
- 회원 화면은 `PAGE_M('<이름>',slot,'<제목>')` — slot 23 부터 새로 쓴다(0~22 는 이미 씀).
- 결정이 필요한 곳은 묻지 않는다. `_workspace/role-essentials/provisional-decisions.md` 의 임시 확정 기준대로 그리고 노트에 적는다.
- 문법 점검 명령에서 매개변수 `'B'` 는 뺀다(파일 안의 `const B` 와 겹친다).

## 하단 탭이 없는 화면 (2026-11-11)
가입·로그인·비밀번호 찾기·업데이트 안내처럼 하단 탭이 없어야 하는 화면은 틀의 다섯째 인자로 끈다:
`PAGE_M('<이름>',slot,'<제목>',928,{tab:false})` · `PAGE('<이름>',5280,'<제목>',928,{tab:false})` · `PAGE_O('<이름>',3080,'<제목>',928,{tab:false})`.
탭을 끄면 내용은 y 84~870 까지 쓸 수 있고 맨 아래 주 버튼은 y 850 근처에 둔다.

## 보드 배치 (2026-11-13 재배치 뒤)
페이지는 **역할 기둥 넷**으로 나뉜다 — 회원 앱(x 0) · 강사 앱(x 6200) · 대표 앱(x 12400) · 관리자 웹(x 18600). 기둥 사이에 세로 구분선이 있고, 기둥 안은 흐름별 소제목 줄(예: `01-13 수업 상세·신청·결제`, `W-5 수업·포스터 등록·행사·휴강`)이다. 줄 목록과 좌표 계산은 `boards/relayout_*.js` 와 재배치 계획(`plan.py`, 기록은 `docs/guide/penpot-mcp-guide.html`)에 있다.
- 틀(`PAGE_M`·`PAGE`·`PAGE_O`·`WEB`)은 새 보드를 **그 역할 기둥 아래 임시 줄(y 24300)** 의 빈 자리에 놓는다. `slot`·`minX` 인자는 이제 위치에 쓰이지 않는다(옛 스크립트와 호출 모양을 맞추려고 남겼다).
- 그린 뒤에는 오케스트레이터가 보드를 **맞는 소제목 줄의 끝**으로 옮긴다(`b.x`·`b.y` 만 바꾼다). 임시 줄에 남겨 두지 않는다.
- 이전 안·폐기 보드는 `99 · 보관`(x 0, y 33924 아래)으로 옮긴다.
