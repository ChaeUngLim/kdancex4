### 보드 연결·다듬기(기존 보드 수정)
- M1B 「강사 회원가입」 → I31 → I31C. 「아이디 찾기 | 비밀번호 찾기」 → I31B.
- I2D(수업 만들기 2/2)의 다음 → I32. I2D 의 버튼이 바로 `수업 등록`이면 I32 를 사이에 끼운다.
- I19 자이브(입문) 임시 저장 카드 → I33. I21 알림함에 「수정 요청」 줄(→ I33) 추가.
- I6B 「시간 · 장소 변경 ›」 → I34. I24 「요일·시간」 줄 설명과 I34 의 「이후 회차 모두」가 같은 길이다.
- I1 홈 → 수업이 없는 날은 I35. I5·I5D·I5W `+ 개인 일정` → I36.
- I8(플러스 끝난 홈)과 I36B 를 같은 「끝남」 묶음으로 둔다. I8 「알아보기 ›」·I36B·I37 의 `알아보기` → I9C 시트.
- I9C 시트에 구독 중일 때 `해지하기 ›` 입구(→ I37B) 추가. 지금 I9C 는 체험 중 상태만 있다.
- I19 `지난 수업` → I38. I12 「학원 공지 · 전체 보기 ›」 → I39. I9 「강사 소개 · 프로필」 → I40, 「약관 · 개인정보 처리방침」 → I40B.
- 옛 보드 날짜 어긋남(고치지 않음): I12 「10월 9일(목) 한글날」 — 2026-10-09 는 금요일이다(I39 는 「10/9 (금)」으로 그렸다). I11 의 쌈바(입문) 「10/5 ~ 11/25 · 16회」와 I24·I34 의 「11/2 – 12/23 · 16회」가 서로 다르다(I34 는 I24·I25 쪽을 따랐다).
- spec 안의 어긋남(확인 필요): FR-191(로그인 상태 관리)은 「계좌 변경은 관리 웹에서만」이라 적고 I18(정산 계좌 등록)은 강사 앱에서 바꾸게 그렸다(`notes_I2.md` I18 추천안에도 적힌 문제). FR-011 의 Q23(강사 본인확인 시점) 임시 확정(정산 계좌 등록 전)과 FR-112e 의 「체험 시작 전 본인확인」이 시점을 다르게 말한다 — I31C 는 둘을 「체험 때 하면 계좌 등록 때 다시 쓴다」로 이었다.
- 대표 쪽 짝: O5(수업 승인) 의 `수정 요청`에 보낸 시각을 남겨야 I33 이 시각을 보일 수 있다. 대표 캘린더(O23)의 「불가 시간」에 강사 개인 일정(I36)도 들어간다.
