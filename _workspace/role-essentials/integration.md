# 필수 기능 점검 — 문서 반영 지침 (2026-11-10)

근거 보고서: `member.md`(회원 43항목) · `instructor.md`(강사 40항목) · `owner.md`(대표·결제 기반 46항목). 항목 번호(⑪ 등)는 각 보고서의 번호다.
이 문서는 **무엇을 어떻게 반영할지**만 정한다. 문장 초안과 근거 줄번호는 각 보고서 2절에 있다.

## 0. 공통 원칙

1. 새로 넣는 규칙은 사용자가 정한 것이 아니다. 모두 `**[보완 2026-11-10 — 필수 기능 점검, 추천안·사용자 확인 대기]**` 를 붙인다.
2. 이미 사용자가 정한 문장은 고치지 않는다. 고쳐도 되는 곳은 3절 「어긋남 정리」에 적은 것뿐이다.
3. 돈의 흐름·법률·세무처럼 사용자 결정이 먼저인 것은 규칙을 지어내지 않고 4절 「결정 질문」으로 올린다.
4. 외부 API 가 필요한 항목(예금주 확인, 사업자 상태 조회, 본인확인)은 「무료 구간 안에서 가능한 방법으로 — 방법은 확인 필요」라고 적는다(유료 API 를 전제하지 않는다).
5. 추천값은 `추천값 N` 으로 적어 확정값과 구별한다.
