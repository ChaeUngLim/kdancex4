# 임시 확정 기준 (2026-11-10 밤)

사용자 지시: 「확인받지 말고 우선 다 구현해 주고, 이후에 수정할 부분을 다시 질문해서 고치는 방식(HITL)으로 한다. 필요한 부분은 지금까지 내가 최종 결정한 기준을 바탕으로 한다.」
그래서 아직 답을 받지 못한 결정 질문은 **아래 추천안으로 임시 확정**하고 문서·보드를 끝까지 만든다. 문서에는 `**[임시 확정 2026-11-10 — 추천안으로 진행, 사후 확인]**` 을 붙여 사용자가 정한 것과 구별한다. 이전 문장은 지우지 않고 「이전:」으로 남겨 되돌릴 수 있게 한다.

## 1. 사용자가 이미 정한 것 (바꾸지 않는다)
- 결제수단: 이벤트·원데이·파티·공연·대회는 간편 계좌이체(기본)·가상계좌만. 정규·단기·개인 레슨은 신용·체크카드 기본. 이유는 카드 수수료(FR-111·FR-111a·FR-280).
- 출결: 기본은 출석이고 회원이 결석 예정을 고른다. QR 출석·호명은 없다. 2026-11-19 부터 강사·대표도 수업이 끝난 뒤 결석을 대신 표시할 수 있다(이전: 회원 자율, 강사 체크 없음). 결석은 레벨에만 쓴다(Q15).
- 관리자 웹: 로그인 하나·콘솔 하나, 메뉴는 권한으로(FR-300). 정산은 대표가 전체 강사를 보고 강사는 본인 것만(FR-135).
- 결석 예정은 수업마다 `참석 | 결석` 토글 하나(FR-092e).
- 색·모양: 아이보리 바탕 + 딥 플럼(#5b3a63) 강조 + 샴페인은 가는 선·로고만. 녹색·갈색·주황 금지. 하단 탭은 모든 화면에. 유료는 「멤버십」, 「구독」은 학원 소식 받기. Owner 는 「대표」. 「쌈바」 표기. 레벨의 나이 표현은 화면에 쓰지 않는다. 강사 평가 레벨은 회원에게 숨긴다.
- 운영자는 앱·웹 시스템만 관리. 환불·분쟁은 대표.
- 외부 API 는 무료 구간만(결제 PG 자체는 예외). 2026-11-19 확정(R15): 휴대폰 본인확인도 건당 유료지만 필수 유료 예외로 허용한다(업체·금액은 정식 운영 전 확인, 베타는 가짜 본인확인). 사업자 상태 조회는 공공데이터포털 국세청 상태조회 API(영구 무료), 예금주 확인은 통장 사본 수동 확인(유료 API 없음).

## 3. 2026-11-19 사용자 결정 (확정)
- 정규 수업 중도 환불: 학원이 공지한 환불 기준 %로 금액을 미리 채우고 대표가 고칠 수 있다. 거절과 근거 입력도 둔다(FR-293). 이전: 금액 칸을 비움.
- 초대 링크로 가입한 강사도 승인 대기로 들어간다(FR-011). 이전: 초대 링크면 바로 소속.
- 이벤트형 취소 수수료 「6일 전~3일 전」은 20%(FR-099c).
- 카드·간편 계좌이체 결제 기한은 15분(FR-285 전제 18, Q39). 이전: 30분.
- 레벨업: 정기 수업을 끝까지 마치고 출석 70% 이상이면 한 칸. 결석은 회원·강사·대표가 표시한 것을 센다(FR-169a). 결석 표시 기한은 수업 종료 뒤 48시간(추천안, 사용자 확인 대기).
- 유료 상품 이름은 회원·강사·대표 모두 「멤버십」. 구분이 필요하면 「강사 멤버십」「대표 멤버십」. 「구독」은 학원 소식 받기만.
- 1:1 개인 레슨은 결제 대기여도 강사에게 수강생 이름을 보인다. 「결제 대기 N명」은 단체 수업 명단에만 적용.
- Q33(강사 몫 비율) 확정: 대표가 강사마다 기본 비율을 정하고 수업별(개인 레슨 포함) 예외를 줄 수 있다. 기본값 없음 — 소속 승인 때 함께 입력. 빈칸이면 지급 표에서 빼고 알린다(안전망). 학원 직원 강사는 비율 없음.
- 개인 레슨 플랫폼 수수료는 1%(이전 5%). 일반 수업·행사 5% 그대로. 입점 1년 면제(0%)는 개인 레슨에 적용하지 않고 첫날부터 1%(사용자 확정).
