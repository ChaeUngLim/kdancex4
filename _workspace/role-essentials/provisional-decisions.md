# 임시 확정 기준 (2026-11-10 밤)

사용자 지시: 「확인받지 말고 우선 다 구현해 주고, 이후에 수정할 부분을 다시 질문해서 고치는 방식(HITL)으로 한다. 필요한 부분은 지금까지 내가 최종 결정한 기준을 바탕으로 한다.」
그래서 아직 답을 받지 못한 결정 질문은 **아래 추천안으로 임시 확정**하고 문서·보드를 끝까지 만든다. 문서에는 `**[임시 확정 2026-11-10 — 추천안으로 진행, 사후 확인]**` 을 붙여 사용자가 정한 것과 구별한다. 이전 문장은 지우지 않고 「이전:」으로 남겨 되돌릴 수 있게 한다.

## 1. 사용자가 이미 정한 것 (바꾸지 않는다)
- 결제수단: 이벤트·원데이·파티·공연·대회는 간편 계좌이체(기본)·가상계좌만. 정규·단기·개인 레슨은 신용·체크카드 기본. 이유는 카드 수수료(FR-111·FR-111a·FR-280).
- 출결: 회원 자율. 기본은 출석이고 회원이 결석만 고른다. 강사가 오늘 인원을 파악하는 용도. 강사 체크·QR 출석 없음(Q15).
- 관리 웹: 로그인 하나·콘솔 하나, 메뉴는 권한으로(FR-300). 정산은 대표가 전체 강사를 보고 강사는 본인 것만(FR-135).
- 결석 예정은 수업마다 `참석 | 결석` 토글 하나(FR-092e).
- 색·모양: 아이보리 바탕 + 딥 플럼(#5b3a63) 강조 + 샴페인은 가는 선·로고만. 녹색·갈색·주황 금지. 하단 탭은 모든 화면에. 유료는 「멤버십」, 「구독」은 학원 소식 받기. Owner 는 「대표」. 「쌈바」 표기. 레벨의 나이 표현은 화면에 쓰지 않는다. 강사 평가 레벨은 회원에게 숨긴다.
- 운영자는 앱·웹 시스템만 관리. 환불·분쟁은 대표.
- 외부 API 는 무료 구간만(결제 PG 자체는 예외).

## 2. 임시 확정 (추천안으로 진행)
| 질문 | 임시 확정 |
|---|---|
| Q14(돈이 흐르는 길) | 강사는 정산 계좌를 등록한다. 정산일에 앱이 강사별 지급액을 계산하고, **대표가 확인·승인하면 한 번에 지급**한다. 베타: 대표가 지급 대상 목록(이름·계좌·금액)을 내려받아 은행 대량이체로 보내고 앱에서 「지급 완료」를 누른다. 정식 운영: 같은 승인 버튼이 PG 지급대행을 호출한다. 플랫폼은 돈을 보관하지 않는다. 대표가 정산일 뒤 추천값 5영업일 안에 승인하지 않으면 강사와 대표에게 다시 알린다. 원천징수(3.3%)는 보수를 주는 학원 몫으로 보고 명세에 금액만 표시(세무 확인 필요). 개인 레슨도 같은 흐름, 수수료 5% |
| Q15 뒤처리 | 결석 알림은 어떤 불이익에도 연결하지 않는다. ① 레벨업 조건: 「출석 70% 이상」→ **「정기 수업을 끝까지 마치면 1칸」**(이전 규칙은 「이전:」으로 남김) ② 노쇼 기록·대기 순번 불이익(FR-167) 보류 ③ 노쇼 회차 정산 기준(FR-135c)은 하나로 고정 — 빠진 회차는 환불·보강 없음, 화면(W8)은 고르는 화면이 아니라 안내 ④ 출석 기록을 분쟁 근거로 쓰는 문장(FR-104·FR-135b)은 「결제·환불 기록을 근거로」 ⑤ 화면의 「출석 N회 중 M회」·출석률 열은 뺀다. 대신 「결석 예정」 표시만 |
| Q16(휴강 환불·보강) | 크레딧을 따로 만들지 않는다. 휴강이 확정되면 회원이 7일 안에 「같은 과정의 다른 회차로 옮기기」 또는 「그 회차 금액 환불(결제액 ÷ 회차 수)」을 고르고, 고르지 않으면 환불 |
| Q17(미성년자 결제 동의) | 베타에서는 만 19세 이상만 직접 결제. 만 14~18세는 만 14세 미만과 같이 보호자 계정의 자녀로 등록해 보호자가 결제(법률 검토 대상) |
| Q18(세금 서류) | 수업료의 현금영수증·세금계산서는 판매자(학원) 명의. 플랫폼은 자기 수수료·예매 수수료·멤버십에 대해서만 발행. 플랫폼은 주민등록번호를 받지 않는다(세무 확인 필요) |
| Q19(정산 명세 내보내기) | 넣는다. 대표·강사가 기간을 골라 CSV 로 받는다. 강사는 본인 것만 |
| Q20(강사 명단 표시 범위) | 이름 + 가운데를 가린 연락처, 결제 완료만. 결제 대기는 인원 숫자로만 |
