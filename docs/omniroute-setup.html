OmniRoute 왕초보 가이드

가장 최신·고성능 무료 AI 모델 6개를 프론트엔드/백엔드 용도에 맞춰 성능 순서대로 연결합니다. 코딩을 몰라도 따라 할 수 있도록 클릭 단위로 적었습니다.

연결 방식은 두 가지뿐입니다 — OAuth(그냥 구글/깃허브 같은 기존 계정으로 로그인, 가입 불필요)와 API 키(사이트에 가입한 뒤 발급받는 긴 비밀번호 같은 문자열). 아래 각 카드에 어떤 방식인지 표시돼 있습니다.

최후 보루
  1. 1
    프론트엔드난이도: 쉬움 · OAuth

    최신 모델이면서 UI/프론트엔드 코드 생성 벤치마크에서 무료 모델 중 최상위권 — 1순위로 연결.

    ① 계정 만들기

    1. 따로 가입할 필요 없음 — 아래 연결 과정에서 자동으로 처리됨

    ② OmniRoute에 연결하기

    1. 브라우저에서 http://localhost:20128 접속 → 설정한 비밀번호로 로그인
    2. 왼쪽 메뉴에서 Providers 클릭
    3. Connect Qoder 버튼 클릭
    4. 뜨는 창에서 이메일 인증 또는 소셜 로그인 진행
    5. 연결되면 모델 목록에 GLM-4.7이 자동으로 나타남
  2. 2
    프론트엔드백엔드난이도: 쉬움 · OAuth

    무료 모델 전체를 통틀어 실제 판단력·코드 품질이 가장 좋음. 대신 한도가 적어서(월 약 50회) 정말 중요한 작업에만 아껴 써야 함.

    ① 계정 만들기

    1. AWS Builder ID가 없다면 이메일만으로 무료로 즉시 생성 가능 (또는 기존 Google/GitHub 계정 사용)

    ② OmniRoute에 연결하기

    1. Dashboard → Providers → Connect Kiro 클릭
    2. AWS Builder ID 또는 Google/GitHub 선택 후 로그인
    3. 권한 허용 화면에서 Allow 클릭
    4. 완료되면 Claude Sonnet, Claude Haiku가 목록에 추가됨
    무료 한도월 ~50 크레딧
  3. 3
    백엔드난이도: 이미 연결됨

    여러 파일을 한 번에 참고해야 하는 큰 백엔드 작업(긴 컨텍스트)에 강함.

    ① 계정 만들기 / ② 연결하기

    1. 1번에서 Qoder를 이미 연결했다면 별도 작업이 필요 없음
    2. 확인만: Dashboard → Providers → Qoder 항목 열어서 kimi-k2 모델이 체크돼 있는지 확인
  4. 4
    백엔드난이도: 보통 · API 키

    로직·알고리즘·추론이 필요한 백엔드 코딩에서 무료 모델 중 최상위권.

    ① API 키 만들기

    1. platform.deepseek.com 접속 → 이메일로 회원가입
    2. 로그인 후 왼쪽 메뉴 API Keys 클릭
    3. Create API Key 클릭 → 이름은 아무거나 입력 → 생성
    4. sk-로 시작하는 긴 문자열이 뜨면 바로 복사 (다시 볼 수 없으니 꼭 지금 복사)

    ② OmniRoute에 연결하기

    1. Dashboard → Providers → Add Provider
    2. 목록에서 DeepSeek 선택
    3. 복사한 키를 API Key 칸에 붙여넣기 → Save
    무료 한도월 ~5M 토큰
  5. 5
    프론트엔드백엔드난이도: 쉬움 · OAuth

    무료 한도가 압도적으로 커서(월 약 6천만 토큰) 반복적인 대량 작업의 폴백으로 최적. 단, Flash 계열만 무료(Pro는 유료로 전환됨).

    ① 계정 만들기 / ② 연결하기

    1. Dashboard → Providers → Connect Gemini 클릭
    2. 평소 쓰는 구글 계정으로 로그인 → 권한 허용
    3. 완료
    무료 한도월 ~60M 토큰
  6. 6
    백엔드난이도: 보통 · API 키

    무료 풀 자체가 가장 커서(월 약 10억 토큰) 위 5개가 전부 소진돼도 쓸 수 있는 최후의 보루.

    ① API 키 만들기

    1. console.mistral.ai 접속 → 회원가입 (카드 등록 불필요)
    2. API Keys 메뉴 → Create new key
    3. 생성된 키 복사

    ② OmniRoute에 연결하기

    1. Dashboard → Providers → Add Provider → Mistral 선택
    2. 복사한 키 붙여넣기 → Save
    무료 한도월 ~1.0B 토큰
  7. 7
    1~6단계 완료 후 진행

    6개를 각각 연결만 해서는 자동 전환이 안 됨 — 우선순위를 정해줘야 함.

    연결하기

    1. Dashboard → Combos → Create New
    2. 이름 예: my-fallback
    3. 위 표의 화살표 순서 그대로 우선순위 등록: glm-4.7 → claude-sonnet → kimi-k2 → deepseek-v3.2 → gemini-flash → mistral
    4. Strategy는 Priority 선택 (1번이 막히면 자동으로 다음으로 넘어감)
