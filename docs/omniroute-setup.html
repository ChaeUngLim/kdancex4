    프론트엔드난이도: 보통 · API 키

    Qoder 경유 GLM-5.2는 14일 체험판(300크레딧)이 끝나면 프리미엄 모델 접근이 막히는 "가입 축하금" 구조라 무료 기준에서 제외 — 대신 Z.ai 자체 API가 GLM-4.7-Flash를 카드 등록·만료 없이 영구 무료로 제공. UI/프론트엔드 코드 생성에서 여전히 무료 모델 상위권.

    ① API 키 만들기

    1. z.ai (또는 open.bigmodel.cn) 접속 → 이메일로 회원가입 (카드 등록 불필요)
    2. 콘솔에서 API Keys 메뉴 → Create API Key
    3. 생성된 키 복사

    ② OmniRoute에 연결하기

    1. 브라우저에서 http://localhost:20128 접속 → 로그인 → 왼쪽 메뉴 공급자
    2. 공급자 검색창에 Z.ai 또는 Zhipu 입력 → 카드 클릭
    3. 복사한 키를 API Key 칸에 붙여넣기 → Save → 모델 목록에서 glm-4.7-flash 활성화
    무료 한도영구 무료 · $0 입력/출력(만료·카드등록 없음, 정확한 요청 속도 제한은 콘솔에서 확인)

    1~5단계 완료 후 진행

    백엔드는 4개를 순서대로 폴백해도 되지만(작업 성격이 비슷해서 "일단 제일 좋은 걸로, 막히면 다음"이 자연스러움), 프론트엔드 3개는 성격이 서로 달라서(판단력 vs 코드 생성 vs 예비) 순차 폴백보다 역할별로 나눠 쓰는 게 낫다 — 특히 Claude Sonnet의 월 50회 한도를 아무 작업에나 먼저 쓰지 않고 정말 판단이 필요한 곳에만 아껴 쓸 수 있음.

    ① 백엔드 — Combo로 등록 (자동 폴백, 2026-09-18 실제 생성·테스트 완료)

    1. Dashboard → Combos → + 콤보 생성
    2. 이름: Free-fallback (처음 계획했던 be-fallback이 아니라 실제로는 이 이름으로 생성·테스트 완료됨)
    3. 순서 등록: kiro/claude-sonnet-4.5 → groq/qwen/qwen3.8-27b → gemini/gemini-3.8-flash → mistral/codestral-latest
    4. Strategy: 우선순위(Priority) (앞 순서가 막히면 자동으로 다음 순서로 폴백)
    5. 응답 검증의 "금지된 하위 문자열"은 기본값(I cannot help, as an AI) 유지 — 거절 응답 나오면 자동으로 다음 모델로 폴백됨

    ② 프론트엔드 — Combo로 묶지 않고 상황별로 직접 지정

    1. 설계·판단이 필요한 작업(화면 구조를 어떻게 짤지, 상태관리를 어디에 둘지 등) → kiro/claude-sonnet-4.5를 직접 지정해서 호출
    2. 실제 컴포넌트/UI 코드 작성(폼, 리스트, 스타일링 등 구체적인 코드) → zai/glm-4.7-flash를 기본값으로 호출
    3. 같은 패턴의 대량 반복 작업(비슷한 화면 여러 개, 일괄 스타일 적용) → 이것도 zai/glm-4.7-flash가 담당한다. 만료 없는 영구 무료라 프론트엔드에서 물량을 받아낼 수 있는 유일한 모델이다.
    4. 예비(비상용) → gemini/gemini-3.8-flash — 하루 20건뿐이라 대량 작업엔 못 쓰고, GLM이 막혔을 때 중요한 몇 건에만 쓴다
    5. 안전망이 필요하면 별도로 fe-fallback Combo(kiro/claude-sonnet-4.5 → zai/glm-4.7-flash → gemini/gemini-3.8-flash, Priority, 아직 미생성)도 만들어두고, 지정한 모델의 한도가 막혔을 때만 이걸로 대체

    마지막 단계

    지금까지는 OmniRoute 안에서만 준비된 상태 — Claude Code가 실제로 이걸 쓰게 하려면 마지막으로 연결.

    방법 A — 실행 스크립트 (추천, 2026-09-18 검증 완료)

    cd ~/kdance
scripts/claude-free.sh

    게이트웨이 생존 확인 → ~/.claude.json에서 키 자동 주입 → ANTHROPIC_MODEL=Free-fallback 지정까지 한 번에 처리한다. claude에 넘길 인자는 그대로 전달된다(scripts/claude-free.sh --continue).

    방법 B — 수동 환경변수

    export ANTHROPIC_BASE_URL=http://localhost:20128
export ANTHROPIC_API_KEY=<~/.claude.json 의 omniroute Authorization 값>
export ANTHROPIC_MODEL=Free-fallback
claude

    주의 ① 지금 열려 있는 터미널이 아니라 새 터미널에서 실행해야 한다 — 환경변수는 이미 실행 중인 프로세스에 소급 적용되지 않는다. 주의 ② omniroute run claude --model auto의 auto는 OmniRoute 내장 자동 라우터라 우리가 만든 Free-fallback 콤보를 타지 않는다 — 모델명을 직접 지정해야 한다.
