# 강사 — 관리자 웹에서 하는 일 (대표가 권한을 맡겼을 때만)

> 이 파일은 **화면 기준 목록**이다. 규칙의 원문은 [`instructor.md`](./instructor.md)(강사 기능 정의서)와 `specs/001-ai-dance-class-platform/spec.md` 에 있고, 여기에는 복사하지 않았다. 다르면 spec 이 맞다.
> 근거는 spec FR-081a(강사 위임 범위) · FR-300(로그인 하나·콘솔 하나) · FR-011a(역할별 화면·강사·대표 입구)다. 보드 번호는 2026-11-13 에 Penpot 보드 이름과 대조했다.

## 강사가 관리자 웹을 쓰는 때

- 강사에게는 관리자 웹이 기본으로 열려 있지 않다. **대표가 권한을 맡긴 강사만** 들어온다.
- 강사 전용 웹이 따로 있는 것이 아니다. 대표와 같은 로그인 화면·같은 콘솔로 들어오고, 맡은 메뉴만 보인다 — FR-300. 보드 W1c(권한별 메뉴).
- 관리자 웹 로그인은 2단계 인증(인증 앱 6자리 — 2026-11-18 패스키 뺌)을 거친다 — FR-303(관리자 웹 2단계 인증).
- 대표가 권한을 끄면 그 순간부터 그 강사의 관리자 웹 요청은 거부된다. 권한을 바꾼 기록은 전후 값으로 남는다.

## 맡을 수 있는 일 (위임 2종)

대표가 대표 앱(O38)이나 관리자 웹에서 종류별로 켜고 끈다.

| 위임 종류 | 화면 (보드) | 웹에서 하는 일 | 근거 | 정의서 |
|---|---|---|---|---|
| 예약·명단 | W23 | 학원 **전체** 수강생 조회, 수업별 예약 명단, 인원 관리(현장 등록 포함) | FR-081a · FR-079 · FR-106 | 3.3 |
| 수업·포스터 등록 | W30 | 수업 등록과 취소, 포스터 한 장으로 수업 등록(자동 추출 → 검토 → 게시) | FR-081a · FR-073 ~ FR-076 | 3.2 |

권한을 맡은 강사가 올린 수업도 대표가 승인해야 공개된다 — FR-050a(수업 등록 승인).

## 맡을 수 없는 일

대표 고유 권한이라 어떤 강사에게도 넘기지 않는다.

| 볼 수 없는 것 | 근거 |
|---|---|
| 매출, 정산, 금액 설정, 재무 대시보드 | FR-081a(강사 위임 범위) |
| 주문·결제 목록 | FR-079a(대표 주문·결제 목록) — 추천안, 확인 대기 |
| 환불 금액 입력과 실행 | FR-098b(환불 요청 경로) |
| 강사 권한 위임, 강사 소속 승인·해제 | FR-081 · FR-071 |
| 정산 계좌, 환불·취소 공지 양식 | FR-139 · FR-099a |

## 알아 둘 어긋남

`permissions.md` 로 옮긴 옛 12장에는 Web 대상에 「강사 Web」이 따로 적혀 있다. 지금 spec 에는 강사 전용 웹이 없다. 강사는 위에 적은 대로 위임받은 메뉴만 대표와 같은 콘솔에서 쓴다. 12장 문장은 그 전 기록이다.
