# 대표 — 대표 앱에서 하는 일

> 이 파일은 **화면 기준 목록**이다. 규칙의 원문은 [`owner.md`](./owner.md)(대표 기능 정의서)와 `specs/001-ai-dance-class-platform/spec.md` 에 있고, 여기에는 복사하지 않았다. 다르면 spec 이 맞다.
> 근거는 spec FR-011a(역할별 화면·강사·대표 입구)다. 보드 번호와 화면 이름은 2026-11-13 에 Penpot 보드 이름과 대조했다.

## 대표 앱이 무엇인가

- **강사·대표 앱** 안의 대표 화면이다. 회원 앱과는 다른 앱이고(앱 둘·서버 하나), 아이디·비밀번호로 로그인한다. 로그인한 역할에 따라 강사 화면과 대표 화면이 바뀐다.
- 대표 계정은 스스로 가입할 수 없다. 입점 신청을 운영자가 승인해야 열린다.
- 원칙: **휴대폰에서 할 수 있는 일은 대표 앱에서도 한다**(2026-11-13 개정). 규칙은 관리자 웹과 같고 화면만 휴대폰에 맞춘다.
- **돈이 실제로 나가는 일은 `승인` 버튼을 누르면 확인 팝업(금액·회원·되돌릴 수 없음)이 한 번 더 뜬다**(2026-11-18 — 지문·얼굴 패스키는 쓰지 않는다).
- 아래 탭은 `홈 · 캘린더 · 수업 · 학원 · 마이` 다섯 개다.
- 보드 번호 주의: **O1 ~ O4 는 이름이 O 로 시작하지만 관리자 웹 화면이다**([`owner-web.md`](./owner-web.md)). 대표 앱은 O5 부터다.

## 앱에서 하지 않는 일

정산 계좌 변경, 정산 명세 엑셀(xlsx)(2026-11-24 변경 — 이전: CSV), 강의실 주간표 배정, 환불·취소 공지 양식 작성, 행사 등록과 행사 일괄 취소, 입점 신청과 입점 해지, 가격·시간·장소 변경, 차지백 소명 자료 올리기, 회원 전체 보기·내려받기. 이유와 근거는 [`owner-web.md`](./owner-web.md)의 「웹에서만 하는 일」에 있다.

## 아직 정하지 않은 것

- 환불 실행(O48B) 뒤의 결과 화면과 자주 묻는 질문 「고치기」(O42) 화면이 보드에 없다.
- O47 의 「기한 안에 올리지 않으면 이의제기가 받아들여져요」 문구는 spec 에 근거가 없다. 사용자 확인 대기다.
