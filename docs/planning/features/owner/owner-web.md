# 대표 — 관리자 웹에서 하는 일

> 이 파일은 **화면 기준 목록**이다. 규칙의 원문은 [`owner.md`](./owner.md)(대표 기능 정의서)와 `specs/001-ai-dance-class-platform/spec.md` 에 있고, 여기에는 복사하지 않았다. 다르면 spec 이 맞다.
> 웹·앱 구분의 근거는 spec FR-011a(역할별 화면·강사·대표 입구)의 「휴대폰에서 할 수 있는 일은 대표 앱에서도 한다」(2026-11-13 개정)다. 보드 번호와 화면 이름은 2026-11-13 에 Penpot 보드 이름과 대조했다.

## 관리자 웹이 무엇인가

- 대표의 **본 작업장**이다. 대표가 할 수 있는 일은 전부 여기서 된다.
- 로그인 하나·콘솔 하나다. 대표, 위임받은 강사, 운영자가 같은 화면으로 들어오고 권한에 따라 메뉴만 다르게 보인다 — FR-300(로그인 하나·콘솔 하나). 보드 W1c.
- 비밀번호 뒤에 2단계 인증을 거친다. 인증 앱 6자리 코드를 넣는다(2026-11-18 — 지문·얼굴 패스키는 쓰지 않는다) — FR-303(관리자 웹 2단계 인증). 보드 W1a(로그인) → W1b2(인증 앱 6자리). W1b·W1b3(패스키)은 이전 안.
- 보드 번호 주의: **O1 ~ O4 는 이름이 O 로 시작하지만 관리자 웹 화면이다.** O1(대시보드)은 W29 로 대체됐다.

## 운영자만 보는 메뉴

같은 콘솔의 「플랫폼 정산」 메뉴는 운영자 계정에만 보인다. 조회 전용이고, 바꿀 수 있는 값은 수수료율·공휴일·예금주 확인·사업자 점검 소명 처리 넷이다(2026-11-20 보드 대조 — 이전: 「수수료율 하나다」, spec FR-301). 내용은 [`../permissions.md`](../permissions.md)의 「플랫폼 관리자 정산 콘솔」 절에 있다 — FR-300 ~ FR-319. 보드 P1 ~ P11 을 그렸다(2026-11-20 보드 대조 — 이전: 「P1 ~ P8 은 아직 그리지 않았다」).

## 알아 둘 어긋남

- `permissions.md` 로 옮긴 옛 12장은 Mobile 대상을 「일반 사용자·강사」로만 적었다. 2026-10-05 이후 spec 은 대표도 강사·대표 앱을 쓰도록 정했고, 2026-11-13 에 앱에서 하는 일을 넓혔다. 12장 문장은 그 전 기록이다.
- 보드 이름에 「관리자 웹」과 옛 표기 「대표 웹」이 섞여 있다. 같은 것을 가리킨다(2026-11-20 보드 대조 — 이전: 「「관리자 웹」과 「관리자 웹」이 섞여 있다」, 치환 찌꺼기). spec FR-300 의 표기는 「관리자 웹」이다.
