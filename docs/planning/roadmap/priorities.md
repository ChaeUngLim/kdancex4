### 핵심 방향

> **kdancex4의 핵심은 "AI 챗봇"이 아니라**
>
> **사용자 → 수업 → 강사 → 일정 → 파티 → 공연**
>
> **전체 K-댄스 활동을 AI가 연결하는 개인화 플랫폼이다.**

이 구조를 기준으로 Web, Mobile, 강사 페이지, 대표 관리자 페이지, AI Agent, RAG, 데이터베이스를 하나의 서비스 아키텍처로 연결한다.

## 2026-11-10 필수 기능 점검이 남긴 결정 질문

spec 의 「필수 기능 점검이 남긴 질문 (2026-11-10)」 표에서 옮겼다. 돈의 흐름·법률·세무처럼 사용자 결정이 먼저인 것이라 규칙을 지어내지 않고 질문으로 둔다. 원본은 spec 이다.

| 질문 | 무엇이 걸려 있나 | 걸린 FR |
|---|---|---|
| Q14(돈이 흐르는 길) | 강사에게 돈을 보내는 주체가 누구인가. 강사 전용 계좌로 지급한다는 쪽(FR-133(강사 전용 계좌), 입점 약관 제9조 ③)과 PG 가 학원 계좌로 지급하고 강사 몫은 학원이 정산한다는 쪽(FR-282d(정산 분배로 학원 직접 지급), FR-135a(개인 레슨 정산 (개설한 학원에서)))이 갈린다. 학원에서 강사로 가는 단계는 어느 문서에도 없다. 원천징수 의무자, 정산 지급 실패, 다른 금액 입금의 반환, 개인 레슨 수수료율이 여기에 막혀 있다 **[임시 확정 2026-11-10 — 추천안으로 진행, 사후 확인]** 강사는 정산 계좌를 등록하고, 정산일에 앱이 강사별 지급액을 계산하며, 대표가 확인·승인하면 한 번에 지급한다. 베타는 대표가 대량이체 뒤 앱에서 「지급 완료」를 누르고 정식 운영은 PG 지급대행을 부른다. 플랫폼은 돈을 보관하지 않는다(FR-133b(강사 정산 지급 흐름)). 이전: 위 질문 그대로 미정 | FR-133 · FR-133a · FR-135a · FR-282d · FR-282e · FR-290 |
| Q15(출결 방식) | **결정(2026-11-10 사용자)**: 출결은 회원 자율이다. 기본은 출석이고 회원이 결석만 고른다. 강사가 오늘 인원을 편하게 파악하는 용도이며, 강사 체크나 QR 출석은 두지 않는다. **남은 것(확인 대기)**: 결석 기록이 회원의 자율 신고뿐이라, 출석 기록을 전제한 요구사항이 근거를 잃는다. 결석을 알린 회원만 불이익을 받으면 회원이 결석을 숨기게 된다. 출석 70% 레벨업, 노쇼 판정, 강사 명단의 출석 열이 막혀 있다 **[임시 확정 2026-11-10 — 추천안으로 진행, 사후 확인]** 레벨업 조건은 「출석 70% 이상」에서 「정기 수업을 끝까지 마치면 1칸」으로 바꾼다. 결석 알림은 어떤 불이익에도 연결하지 않는다(노쇼 기록·대기 순번 불이익 FR-167(반복 노쇼 기록) 보류, 출석 기록을 분쟁 근거로 쓰던 문장은 결제·환불 기록 근거로). 이전: 출석 70% 레벨업, 노쇼 판정, 강사 명단의 출석 열이 막혀 있었다 | FR-104 · FR-135b · FR-135c · FR-166 · FR-167 · FR-169a |
| Q16(휴강 환불·보강) | 「보강 크레딧」이 무엇인가(유효기간, 쓸 수 있는 수업, 안 쓰면 어떻게 되나). 환불을 고르면 금액은 누가 정하나(FR-098(대표 처리 환불 방식)은 대표, FR-059는 시스템이 선택지 제시). 고르는 기한과 안 고를 때의 기본값 **[임시 확정 2026-11-10 — 추천안으로 진행, 사후 확인]** 보강 크레딧을 따로 만들지 않는다. 휴강이 확정되면 회원이 7일 안에 「같은 과정의 다른 회차로 옮기기」 또는 「그 회차 금액 환불(결제액 ÷ 회차 수)」을 고르고, 고르지 않으면 환불한다. 이전: 「보강 크레딧」 선택지 | FR-059 · FR-065 · FR-098 |
| Q17(미성년자 결제 동의) | 만 14세 이상 19세 미만 회원의 결제에 법정대리인 동의를 어떻게 받나. 본인확인 API 는 건당 과금이라 무료 API 원칙과 부딪힌다. 동의 없이 한 결제의 취소권은 어떻게 처리하나. 법률 검토 대상이다 | FR-009 |
| Q18(세금 서류) | 세금계산서 발행 주체, 현금영수증 발행 실행 주체, 수수료 부가세 표시. 원천징수에는 주민등록번호가 필요한데 받지 않기로 한 결정과 부딪힌다. 세무 확인 대상이다 | FR-002 · FR-003 · FR-135d · FR-138 |
| Q19(정산 명세 내보내기) | 정산 내역 내보내기가 요구사항이 아니라고 적은 곳(FR-134)과 내려받기가 있는 곳(변경 이력, 보드 O4)이 갈린다. 대표·강사가 정산 내역을 파일로 받게 할 것인가 | FR-134 |
| Q20(강사 명단 표시 범위) | 강사 명단에 무엇이 보이나. 이름·연락처(FR-112e), 닉네임(FR-019a), 연락처 가림(FR-187) 중 어느 쪽인가. 결제 완료만 보인다는 규칙(FR-005)과 결제 대기도 보여 주는 보드 I10 도 갈린다 | FR-005 · FR-019a · FR-112e · FR-187 |
| Q21(문의 응답 기한) | 문의 응답 기한을 얼마로 두고, 넘기면 무엇을 하나. 위 4.8절의 문의 미응답 재알림 기한이 이 값에 달려 있다 | FR-231 |
| Q22(개인 레슨 환불 공지) | 개인 레슨에 학원 환불·취소 공지를 그대로 쓰나, 따로 양식을 두나. 취소·시간 변경 기한과 수강권 유효기간은 이미 미정이다 | FR-052c · FR-099b |
| Q23(강사 본인확인 시점) | 강사 휴대폰 본인확인을 가입 때 하나, 정산 계좌를 등록하기 전에 하나 | FR-011 · FR-133 |
