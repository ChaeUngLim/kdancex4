# 장르 카테고리 정책 — 살사/바차타 통합

- 날짜: 2026-09-13

## 결정 사항

기존 5개 장르(댄스스포츠 · 아르헨티나 탱고 · 스윙댄스 · 살사 · 바차타) 중
**살사와 바차타를 하나의 카테고리로 통합**한다. 장르는 4종이 된다:

1. 댄스스포츠
2. 아르헨티나 탱고
3. 스윙댄스
4. 살사/바차타

## 적용 범위

- 데이터 모델(장르 enum, `ClassSchedule.genre` 등)을 만드는 시점(로드맵 2단계,
  검색·추천)부터 이 4종 기준으로 설계한다.
- 기존에 배포된 입점 설명회 피치(`social-dance-academy-pitch.html`,
  `소셜댄스_입점설명회.pptx`)와 개발 가이드(`social-dance-app-dev-guide.html`)는
  이번 결정에서 **수정하지 않는다** — 학원 대상으로 이미 쓰인 설명자료라 별도
  요청 시에만 갱신한다.

## 참고

- 색상 매핑(장르별 accent color) 등 UI 토큰도 이 문서를 기준으로 4종에 맞게
  다시 정한다 — 실제 화면 구현 단계에서 확정.
