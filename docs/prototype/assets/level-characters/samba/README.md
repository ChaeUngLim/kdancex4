# 레벨 성장 캐릭터 — 쌈바 샘플 (확정 기준)

2026-10-05 사용자가 "잘 만들어진 구성이야 꼭 기억해 샘플로" 라고 확정한 쌈바 레벨 캐릭터 12장이다. 다른 세부 장르(스탠다드·탱고·스윙·살사·바차타)를 만들 때 이 구성을 기준으로 삼는다. 요구사항은 spec FR-169c(레벨 성장 캐릭터).

| 파일 | 뜻 |
|---|---|
| `m_l01` ~ `m_l10` | 스파이크(남) — 레벨 0~1 아기 · 2~3 초등 · 4~5 중고생 · 6~7 대학생 · 8~9 30대 · 10 40대 귀족 |
| `f_l01` ~ `f_l10` | 페이(여) — 같은 단계 |
| `*.txt` | 그 장을 만든 실제 기록: 라벨, seed·LoRA 세기, 프롬프트, 제외 프롬프트 |
| `gen_samba_v2.py` | 생성 스크립트(로컬 서버 `docs/prototype/local-sd/server.py` 를 부른다) |

## 확정 레시피

- 모델: **Animagine XL 4.0** + LoRA `cowboy-bebop-illustrious-v2`(단계별 세기 0.25~0.6). 로컬 RTX 4060, 비용 없음.
- 한 사람씩 그린다. 장르 카드를 참고 이미지(IP-Adapter)로 넣지 않는다 — 넣었을 때 40대 나이가 묻히고 비율·동작이 어긋났다.
- 고품질: 832×1216 → 1.5배 2단계(1248×1824), DPM++ 2M Karras 35단계, CFG 5, 2단계 세기 0.4. 장당 약 50초.
- 프롬프트 순서: 품질·셀 화풍 → 캐릭터 외형 → 나이 → 의상과 춤 동작 → `cowboy shot, large figure filling the frame`(페이 중고생만 전신) → 한낮의 리우 카니발 배경.
- 레벨 0~5 는 `--younger`(아이 체형: 큰 머리·짧은 팔다리) + 어린이·주니어 라틴 대회복. 미성년 단계는 노출 없는 의상.
- 스파이크도 원작 정장이 아니라 레벨별 댄스복. 제외 태그에 `blue suit, yellow shirt, necktie`.
- 배경에 "brazilian flag colors" 를 넣으면 옷에 국기·축구 유니폼이 그려진다 — 빼고 `sportswear, jersey, flag print` 를 제외한다.
- 구도가 무너지면(아기 얼굴 여럿, 다른 무희) seed 만 바꾼다(`--bump=N`).

⚠ 카우보이 비밥 캐릭터는 권리자 저작물이다. 라이선스를 받기 전까지 내부 프로토타입 전용.
