- **확정:** 2026-10-06
- **칸별 프롬프트:** `m_l01.txt` ~ `f_l10.txt`, **확정 그림:** `m_l01.jpg` ~ `f_l10.jpg`

## 출처 — 칸마다 다른 회차 (스크립트 `gen_tango7.py`, 회차마다 고쳐 가며 생성)

|---|---|
| 스파이크 아기·초등, 페이 초등 | `tango8` (스파이크 초등은 확대 크롭) |
