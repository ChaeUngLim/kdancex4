# 장르별 춤의 정의 (2026-10-03 확정 — 세션 카드의 중심 지시)

브레드의 룸바·쌈바 대비 문장을 기준으로, "A 가 ~라면 B 는 ~" 틀로 네 장르를 정의했다. 카드 프롬프트는 이 정의에서 나온다.

| 장르 | 한 줄 | 악기·무대 |
|---|---|---|
| 댄스스포츠 (룸바) — 쌈바 버전은 별도 카드로 만든다(2026-10-03) | 쌈바는 태양 아래에서 터져 나오는 웃음과 자유의 노래라면, 룸바는 달빛 속에서 속삭이는 그리움과 사랑의 한숨. 룸바가 강렬하게 응축된 열정의 불꽃이라면, 쌈바는 끊임없이 솟구쳐 퍼져나가는 생명의 파동. (브레드) | 현악 오케스트라, 샹들리에 볼룸 |
| 아르헨티나 탱고 | 왈츠가 샹들리에 아래 흐르는 약속의 선율이라면, 탱고는 가로등 아래 멈춰 선 이별의 침묵. 왈츠가 영원을 믿는 자의 회전이라면, 탱고는 떠날 것을 아는 자가 가슴을 맞대고 다리로 쓰는, 끝내 부치지 못한 편지. | 반도네온 연주자, 흩어진 악보, 가로등 |
| 스윙 (린디합) | 왈츠가 손을 잡고 지키는 예절이라면, 스윙은 손을 놓고 되찾는 자유. 왈츠가 바닥을 미끄러지는 우아함이라면, 스윙은 바닥을 박차고 올라 공중에서 웃음으로 다시 만나는 젊음의 반란. | 금관 빅밴드, 1940년대 댄스홀 |
| 바차타 | 살사가 광장에서 터지는 축제의 불꽃이라면, 바차타는 뒷골목 창가에 번지는 연인의 체온. 살사가 온 세상을 향해 열리는 회전이라면, 바차타는 맞닿은 골반이 그리는 작은 원 안에 밤바다 전체를 가두는 고백. | 콩가 연주자, 창가 등불, 밤바다 |

출연진(「천국의 문」): **2026-10-03 결정 — 스파이크·페이·줄리아 세 사람. 룸바·탱고 = 스파이크+줄리아, 스윙·바차타 = 스파이크+페이.** (이전 짝 룸바 스파이크+줄리아 · 탱고 빈센트+카테리나 · 바차타 비셔스+줄리아는 LoRA 가 그 얼굴을 몰라 폐기.) 의상: 룸바 줄리아 빨간 라틴 드레스 · 탱고 줄리아 검은 슬릿 드레스 · 스윙 페이 원작 노란 복장 · 바차타 페이 흰 드레스.
